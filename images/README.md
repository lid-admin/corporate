画像サイズ推奨ガイドライン

ヒーロー画像 (images/hero.jpg)


サイズ： 1920 × 1080px
ファイルサイズ： 300KB 以下
ポイント： 横長で中央を主役にすると、モバイルでも切れにくい


活動レポートの写真 (images/{番号}-{連番}.jpg 例: 17-1.jpg)


サイズ： 長辺 1600px 以下
ファイルサイズ： 250KB 以下
ポイント： カードでは横長にトリミングして表示されるので、横長で撮るか被写体を中央に置くと安全


形式と圧縮


形式： JPEG（品質 75〜80%）が画質とサイズのバランスが良い
WebP に変換するとさらに半分以下になることもある（JPEGのほうが幅広く使える）


圧縮ツール


付属スクリプト（推奨）： ./scripts/optimize-images.py --apply
  images/ の「番号-連番」形式の画像をまとめて縮小します。
  縦横比は変えず、すでに小さい画像には手を付けません。
  --apply を付けないと確認のみで、ファイルは書き換えません。

Squoosh（Web）： https://squoosh.app — 無料、ブラウザ上で完結
Mac プレビュー： エクスポート時に品質スライダーで調整可能

詳しい手順は docs/レポートの追加手順.md を参照してください。
