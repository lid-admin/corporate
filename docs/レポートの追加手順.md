# 活動レポートの追加手順

活動レポートを1本公開するまでの手順です。
HTMLやCSSを書く必要はありません。**写真を置いて、専用ツールでJSONを作るだけ**です。

---

## 必要なもの

- このリポジトリを手元に取得（clone）していること
- ブラウザ（Chrome / Safari など）
- VSCode と拡張機能 [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)（表示確認に使います）
- ターミナル（画像の縮小とGit操作に使います）

---

## 全体の流れ

```
① 写真を準備する  →  ② 写真を置く  →  ③ 本文を作る
        →  ④ ニュースに載せる  →  ⑤ 表示を確認する  →  ⑥ PRを出す
```

---

## ① 写真を準備する

**まず、これから書くレポートの番号（id）を決めます。**

`data/reports.json` を開き、いちばん大きい `id` を探して **+1** した数字を使います。
（2026年9月時点の最大は `16` なので、次は `17`）

写真のファイル名は **`番号-連番.jpg`** の形式にします。

```
17-1.jpg   ← 1枚目（一覧のサムネイルにも使われます）
17-2.jpg   ← 2枚目
17-3.jpg   ← 3枚目
```

**1枚目は一覧ページのカードに出る**ので、いちばん伝わる写真を選んでください。

### 写真の大きさ

スマートフォンで撮った写真はそのままだと大きすぎます（1枚3MBになることも）。
回線の細い場所では表示に時間がかかるため、**必ず縮小してください。**

縮小には用意したスクリプトが使えます。写真を置いたあと（②のあと）に実行してください。

```bash
./scripts/optimize-images.py            # 何が起きるか確認する（書き換えない）
./scripts/optimize-images.py --apply    # 実際に縮小する
```

手作業でやる場合は [Squoosh](https://squoosh.app) が便利です。
目安は **長辺1600px以下・250KB以下** です。

---

## ② 写真を置く

`images/` フォルダに、①で決めた名前のまま置きます。

```
images/17-1.jpg
images/17-2.jpg
```

置いたら縮小スクリプトを実行します。

```bash
./scripts/optimize-images.py --apply
```

---

## ③ 本文を作る

**`data/report-editor.html` をブラウザで開きます。**

> **重要**: ファイルをダブルクリックで開かないでください。
> ⑤の Live Server を起動してから `http://127.0.0.1:5500/data/report-editor.html`
> を開きます。ダブルクリックで開くとタグの一覧が読み込めません。

1. 画面上部の**ファイル選択**から `data/reports.json` を読み込む
2. **「新規作成」**を押す
3. 各項目を入力する

| 項目 | 内容 |
|---|---|
| id | ①で決めた番号（自動で入ります） |
| 日付 | 活動した日 |
| タグ | 選択肢から選ぶ（→ [タグについて](#タグについて)） |
| 著者 | 参加したメンバー。連名は「・」でつなぐ（例: `宮本・和田`） |
| タイトル | 一覧に出る見出し |
| 概要 | カードに出る1〜2文の要約 |
| 本文 | レポート本体（→ [本文の書き方](#本文の書き方)） |
| 画像 | `images/17-1.jpg` のように入力 |
| 画像リスト | 記事内に並べる写真をすべて。1枚目も含めます |

4. **「JSONをダウンロード」**を押す
5. ダウンロードされたファイルで `data/reports.json` を**置き換える**

---

## ④ ニュースに載せる

`data/news.json` を開き、**いちばん上**に1件追加します。

```json
[
  {
    "date": "2026-09-25",
    "title": "【活動レポート更新】タイトルをここに",
    "url": "/pages/report.html?id=17"
  },
  ...
]
```

- `title` の先頭には `【活動レポート更新】` を付けます
- `url` の `id=17` は①で決めた番号に合わせます
- 行末のカンマを忘れないでください（次の項目が続くため）

> **飛び先が無いお知らせを載せたいとき**（「〇〇に出展します」など）は
> `"url": ""` と空にしてください。リンクではない行として表示されます。

## ⑤ 表示を確認する

VSCode の拡張機能 **Live Server** で開いて確認します。

`index.html` を右クリックして「Open with Live Server」を選ぶと、
ブラウザが立ち上がります（既定のポートは 5500）。

| 確認する場所 | URL |
|---|---|
| トップページ | http://127.0.0.1:5500/ |
| レポート一覧 | http://127.0.0.1:5500/reports.html |
| 追加した記事 | http://127.0.0.1:5500/pages/report.html?id=17 |

**見るところ**

- [ ] 一覧のカードに写真とタイトルが出ているか
- [ ] 記事を開いて本文の改行が意図どおりか
- [ ] 写真がすべて表示されているか（写真をクリックすると拡大します）
- [ ] ニュースに追加した行が出ていて、押すと記事に飛ぶか

## ⑥ PRを出す

```bash
git switch -c feat/内容がわかる名前     # 例: feat/rice-harvest
git add .
git commit -m "稲刈り体験レポートの追加"
git push -u origin feat/内容がわかる名前
```

GitHub でプルリクエストを作成し、レビュー後に `main` へマージします。

> **`main` にマージした時点で公開されます。** 確認は⑤で済ませてからマージしてください。

## タグについて

タグの一覧は **`data/tags.json`** で管理しています。
編集ツールの選択肢も、一覧ページの絞り込みボタンも、すべてこのファイルを見ています。

### 新しいタグを追加したいとき

`data/tags.json` の `tags` に1行足すだけです。

```json
{ "name": "稲刈り", "area": "農業" }
```

- `name` — タグの表示名
- `area` — どの事業分野に含めるか。`IT` / `観光` / `農業` / `保育・福祉` のいずれか。
  どれにも当てはまらない場合は `null`
- 並び順が、そのまま一覧ページの絞り込みボタンの順になります

追加したら、壊れていないか確認します。

```bash
python3 -m json.tool data/tags.json
```

> 設定に無いタグを使っても記事は表示されますが、**事業分野からの絞り込みに出てきません。**
> 新しいタグを使うときは `tags.json` にも足してください。

## 本文の書き方

本文はふつうの文章として書きます。HTMLタグは書きません。

| 書き方 | 表示 |
|---|---|
| 空行を1つ入れる | 段落が変わります |
| 改行する | そのまま改行されます |
| `https://` で始まるURL | 自動でリンクになります |

**編集ツールの入力欄では、改行キーをそのまま押してください。**

```
今日は稲刈りに参加しました。
朝から晴れて、絶好の作業日和でした。

午後は乾燥機の使い方を教わりました。
詳しくはこちら https://example.com/ をご覧ください。
```

### `reports.json` を直接編集する場合

**改行キーではなく `\n` と書きます。** JSONの決まりで、文字列の中に
そのままの改行を入れられないためです。

```json
"body": "今日は稲刈りに参加しました。\n朝から晴れて、絶好の作業日和でした。\n\n午後は乾燥機の使い方を教わりました。"
```

- `\n` が1つ → 改行
- `\n\n` が2つ続く → 段落の区切り（あいだに1行分の余白が入る）

編集ツールを使えばこの変換は自動で行われるので、**ツールを使うほうが安全です。**

## つまずいたとき

**編集ツールでタグが選べない**

`file://` で開いています。⑤の Live Server を起動してから
`http://127.0.0.1:5500/data/report-editor.html` を開いてください。
アドレス欄が `file:///Users/...` で始まっていたらこの状態です。

**写真が出ない（「No Image」と表示される）**

- ファイル名が `data/reports.json` の記述と合っているか確認してください（大文字小文字も区別されます）
- `images/` に実際に置かれているか確認してください

**ページが真っ白、または「読み込めませんでした」と出る**

JSONのどこかが壊れています。次のコマンドで場所がわかります。

```bash
python3 -m json.tool data/reports.json
python3 -m json.tool data/news.json
```

よくある原因は、**カンマの付け忘れ・付けすぎ**と、**括弧の閉じ忘れ**です。

**写真の向きがおかしい**

縮小スクリプトは撮影時の向き情報を反映します。
それでもおかしい場合は、元の写真を回転して保存し直してから置き直してください。
